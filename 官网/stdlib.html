#1. 概述与导入

标准库位于 hone_lib/ 目录，全部用 Hone 语言编写。函数统一模块前缀（math_ / coll_ / str_ / gui_ / music_ / sp_ / proc_ / sch_ / img_），通过本地路径 import 使用：

// 本地路径导入（相对路径基于当前工作目录）
import "math" from "./hone_lib/math.hn";
import "collections" from "./hone_lib/collections.hn";
import "str" from "./hone_lib/str.hn";
import "gui" from "./hone_lib/gui.hn";   // 需 v0.3.0+（依赖 server.*）
import "music" from "./hone_lib/music.hn"; // 乐理：音名/音阶/和弦/调性等
import "spider" from "./hone_lib/spider.hn"; // 爬虫：静态直取 + 动态渲染
import "process" from "./hone_lib/process.hn"; // 进程：枚举/查找/结束（跨平台）
import "sched" from "./hone_lib/sched.hn";   // 定时任务：间隔/时刻/cron（跨平台）
import "img" from "./hone_lib/img.hn";     // 图片：绘图/滤镜/变换 + PPM/SVG

// import as：以别名导入，函数名前缀整体替换
import "math" from "./hone_lib/math.hn" as m;   // m_clamp / m_gcd ...

内置模块（无需导入，开箱即用）：除上述纯 Hone 模块外，解释器内置大量模块函数，直接调用即可： crypto.*（md5/sha1/sha256/hmac_sha256/base64）、archive.*（zip/tar.gz 压缩归档）、 zlib.*（zlib/gzip 压缩）、csv.*（CSV 解析/序列化）、 stat.*（均值/中位数/方差/标准差）与 matrix.*（矩阵运算）、 diff.*（文本对比）与 regex.*（find/groups/split）、 glob.*（文件匹配）与 temp.*（临时文件/目录）、 plot.*（SVG 图表）与 yaml.*（YAML 解析/序列化）、 http.request（超时/自定义 Header）、smtp.send（发邮件）、 ws.request（WebSocket）、sqlite.*（SQLite 封装，运行时加载系统库）、 ptr.*（指针类，分配表跟踪防野指针）、plugin.*（插件系统，运行期动态注册）、 server.*（本地 HTTP 服务器）、args.*（命令行参数，支持类型转换与默认值）、 assert（断言，配合 hone test 测试框架）、 input / read_int / read_float（标准输入读取，EOF 报 H306）。完整清单见 语言手册 §8 内置函数参考。

#3. collections 集合模块

列表函数面向数值/同类型列表，元素类型不锁定：

函数说明示例
coll_sum(l)列表求和coll_sum([3,1,4,1,5]) → 14
coll_avg(l)平均值（返回 float）coll_avg([3,1,4,1,5]) → 2.8
coll_max(l) / coll_min(l)最大值 / 最小值→ 5 / 1
coll_unique(l)去重（保持首次出现顺序）→ [3, 1, 4, 5]
coll_count(l, v)统计元素出现次数coll_count([3,1,4,1,5], 1) → 2
import "collections" from "./hone_lib/collections.hn";
l = [3, 1, 4, 1, 5];
print(coll_sum(l));            // 14
print(coll_avg(l));            // 2.8
print(to_str(coll_unique(l)));  // [3, 1, 4, 5]
print(coll_count(l, 1));      // 2

str_empty(s)是否为空字符串str_empty("") → true

print(str_empty(""));           // true
print(str_join([3, 1, 4], "-"));  // 3-1-4
print(str_quote("hi"));         // "hi"

#5. gui 图形界面模块

浏览器渲染 + 本地 HTTP 服务器双向交互的跨平台 GUI（v0.3.0+）。控件均为 dict，gui_run 启动本地服务器并自动打开浏览器。事件回调为约定函数名 on_event(id, value)，返回值按 JSON 协议解释。

函数说明
gui_button(id, label)按钮（点击触发事件）
gui_label(id, text)文本标签（可被 update 更新）
gui_input(id, label, placeholder)输入框（失焦时提交值）
gui_select(id, label, options)下拉选择（options 为字符串列表）
gui_html(html)原始 HTML 片段
gui_run(title, widgets)启动服务器 + 打开浏览器 + 事件循环（Ctrl+C 退出）
import "gui" from "./hone_lib/gui.hn";

// 事件处理：返回值按 JSON 协议解释
fn on_event(id : str, value) -> str {
    if (id == "btn_hi") {
        return json_stringify({"update": [["lbl_out", "你好，Hone GUI！"]]});
    }
    return "";
}

widgets = [
    gui_button("btn_hi", "打招呼"),
    gui_label("lbl_out", "(事件输出)"),
];
gui_run("Hone GUI 演示", widgets);

事件协议：{"update": [[元素id, 新文本], ...]} 更新元素文本、{"alert": "消息"} 弹窗提示、其他文本显示在页面底部状态栏。底层 server.listen / server.poll / server.respond 可直接使用（见 示例 10.2）。

#6. music 乐理模块

音乐理论标准库（纯 Hone 编写）：音名 ↔ MIDI 编号 ↔ 频率换算、音阶与和弦生成、时值与 BPM、音程与移调、调号与调性、顺阶和声、音分与纯律比率。MIDI 编号 60 = C4，A4 = 440Hz。Hone 无 pow/log 内置，频率与音分按十二平均律半音比迭代计算。

函数说明
music_note_to_midi(note) / music_midi_to_note(m)音名 ↔ MIDI 编号（C4=60，A4=69，A#4=70，Bb3=58）
music_midi_to_freq(m) / music_freq_to_midi(freq)MIDI ↔ 频率(Hz)（十二平均律，A4=440）
music_note_to_freq(note)音名 → 频率(Hz)
music_scale(root, name) / music_scale_names()音阶生成（major/minor/dorian/.../blues/chromatic 共 16 种）
music_chord(root, name) / music_chord_names()和弦生成（major/minor/maj7/dom7/sus2/power 等 20 种）
music_beat_sec(bpm)每拍时长(秒)：60 / bpm
music_note_beats(note)音符时值 → 拍数（whole=4 / half=2 / quarter=1 / eighth=0.5 ...）
music_note_dur_sec(bpm, note) / music_dur_sec(bpm, beats)时值 / 拍数 → 秒数
music_interval_name(semitones) / music_interval_between(n1, n2)音程（纯一度/小二度/.../纯八度）
music_transpose(note, semitones) / music_transpose_midi(m, semitones)音名 / MIDI 编号按半音移调
music_shift_octave(note, octaves)音名按八度移调（如 C4 移 1 → C5）
music_key_signature(tonic) / music_key_signature_str(tonic)调号：升/降号数（正/负）与字符串（G→"#"、Eb→"bbb"）
music_relative_minor(tonic) / music_relative_major(tonic)关系小调 / 关系大调（C 大调 → A 小调）
music_circle_of_fifths()五度圈：纯五度上行的 12 个调主音序列
music_diatonic_triads(root, scale) / music_diatonic_sevenths(root, scale)调内顺阶三和弦 / 七和弦
music_harmonize(root, scale)顺阶和声标记（如 C 大调：C4, D4m, E4m, F4, G4, A4m, B4dim）
music_ratio_to_cents(f1, f2) / music_freq_to_cents(freq, ref)频率比 → 音分（2^(1/1200) 迭代逼近）
music_just_ratio(name) / music_just_cents(name) / music_just_names()纯律（自然音程）频率比与音分（如 perfect_fifth ≈ 702 音分）
import "music" from "./hone_lib/music.hn";
print(music_note_to_midi("A4"));       // 69
print(music_midi_to_note(60));       // C4
print(music_midi_to_freq(69));       // 440.0
print(to_str(music_scale(60, "major")));  // [60, 62, 64, 65, 67, 69, 71]
print(to_str(music_chord(60, "maj7")));   // [60, 64, 67, 71]
print(music_note_dur_sec(120, "quarter")); // 0.5（120 BPM 每拍 0.5 秒）

#7. spider 爬虫模块

静态页面直取 + 动态页面渲染的轻量爬虫库（v0.7+，纯 Hone 编写）。设计遵循「渲染服务分离」：Hone 不内置 JS 引擎，动态页面渲染外包给外部服务（node/puppeteer 或 python/playwright），通过 sys.run 通信，Hone 只做请求、解析与提取。所有请求函数返回统一响应 dict：{ok, status, headers, url, text, err}。

函数说明
sp_get(url, opts)智能请求：默认静态直取；{"render": true} 走渲染服务；{"engine": "curl"} 用 curl 拿真实状态码
sp_static(url, opts)静态请求（内置 http.request，零依赖；status 为 0 表示未知）
sp_curl(url, opts)curl 请求（能拿到状态码/响应头，curl 不可用时自动回退 sp_static）
sp_render(url, opts)渲染请求（依次尝试 node 脚本 → python 脚本，输出最终 HTML）
sp_text(html, sel) / sp_text_allCSS 选择器提取元素文本（支持 tag、.class、#id、[attr] 及组合）
sp_attr(html, sel, name) / sp_attr_allCSS 选择器提取属性值
sp_links(html, base)提取页面全部绝对链接（相对 href 自动补全）
sp_cookie_set(jar, name, value) / sp_cookie_getCookie 管理（字符串 jar："a=1; b=2"）
sp_ua_list() / sp_ua_rotate(agents, i)User-Agent 轮换
sp_throttle(seconds)请求限速（防反爬）
sp_body(resp) / sp_json(resp)响应便捷函数：取正文 / 解析正文为 JSON

opts 选项（dict）：ua（User-Agent）、cookie（Cookie jar）、timeout（秒）、retries（重试次数）、delay（重试间隔秒）、method / body（POST 等）、render / engine / render_cmd / render_js / render_py。

import "spider" from "./hone_lib/spider.hn";

// 1. 静态页面：直取 HTML，CSS 选择器提取
r = sp_get("https://example.com/", {});
if (r.ok) {
    for t in sp_text_all(r.text, "div.item") { print(t); }
    for u in sp_links(r.text, "https://example.com/") { print(u); }
}

// 2. 动态页面（JS 渲染）：外包给 node/puppeteer 或 python/playwright
//    后端脚本在 hone_lib/render/，安装后开箱即用：npm i puppeteer
r2 = sp_get("https://spa.example.com/", {"render": true});
print(r2.status, len(r2.text));

// 3. 带 UA 轮换 / Cookie / 限速的批量抓取
uas = sp_ua_list();
jar = "";
i = 0;
while (i < 3) {
    u = sp_ua_rotate(uas, i);
    r3 = sp_get("https://example.com/", {"ua": u.ua, "cookie": jar});
    jar = sp_cookie_set(jar, "visit", to_str(i));
    sp_throttle(1.0);
    i = u.next;
}

渲染后端安装（二选一）：
· Node.js：cd hone_lib/render && npm i puppeteer（或 npm i playwright && npx playwright install chromium）
· Python：pip install playwright && playwright install chromium
脚本输出单行 JSON {"status":200,"headers":{...},"url":"...","html":"..."} 供 Hone 解析。

#8. process 进程模块

跨平台进程检测库（纯 Hone 编写）。Hone 无内置进程 API，本库经 sys.run 调用系统命令实现：Windows 用 tasklist /FO CSV /NH 枚举、taskkill /F /PID 结束；Linux/macOS 用 ps -eo pid=,comm=,args=,rss= 枚举、kill -9 结束。所有查询函数返回进程对象 dict：{pid, name, mem, cmdline}（mem 为 KB；cmdline 仅 Unix 有值，Windows 恒为空）。

函数说明
proc_os()平台识别："windows" / "linux" / "macos" / "unknown"
proc_list()枚举全部进程 → 进程对象列表
proc_find(name)按名称模糊查找（不区分大小写、子串匹配）
proc_exists(name)是否存在指定名称的进程
proc_by_pid(pid)按 PID 反查（未找到返回空 dict）
proc_count(name)匹配进程数量
proc_pids(name)匹配进程的 PID 列表
proc_names()全部进程名（去重）
proc_kill(pid)结束指定 PID 的进程，成功判定：结束后进程不再存在
proc_kill_by_name(name)结束全部同名进程，返回成功数
import "process" from "./hone_lib/process.hn";

os = proc_os();
print(os);   // windows / linux / macos

if (proc_exists("hone.exe")) { print("hone 正在运行"); }

// 枚举 / 模糊查找（Windows 进程名含 .exe，Unix 不含；子串匹配两边通用）
for p in proc_find("chrome") {
    print(p.pid, p.name, p.mem);
}

// 按 PID 反查
info = proc_by_pid(1234);
print(info.name);

// 结束进程
proc_kill(1234);                        // 结束单个 PID
n = proc_kill_by_name("notepad.exe");  // 结束全部同名进程，返回成功数

跨平台差异：name 在 Windows 含扩展名（如 chrome.exe）、Unix 为命令名（如 chrome），请用 proc_find("chrome") 这类子串匹配以保证两边一致；mem 均为 KB；cmdline 仅 Unix 有值。测试脚本见 examples/test_process_lib.hn。

#9. sched 定时任务模块

跨平台定时任务库（纯 Hone 编写）。Hone 不支持函数作为值传递（Value 无函数类型），故任务动作用「命令字符串 + sys.run 执行」，与 cron 心智模型一致：sch_every 按间隔秒执行、sch_at 每天指定时刻执行、sch_cron 按 cron 表达式执行。三种任务构造函数返回任务 dict，放入列表后交给 sch_run 阻塞调度。

函数说明
sch_every(interval, cmd, tag)每 interval 秒执行一次 cmd（间隔任务）
sch_at(hhmm, cmd, tag)每天 "HH:MM" 执行一次 cmd（时刻任务）
sch_cron(expr, cmd, tag)按 cron 表达式执行（5 段：分 时 日 月 周）
sch_run(tasks, seconds)阻塞调度 seconds 秒（0 = 一直运行，Ctrl+C 退出），返回更新后的任务列表
sch_tick(tasks, now)单轮推进：执行到期任务，返回 {"tasks": 新列表, "ran": 本次执行数}
sch_next_hhmm(now, hhmm)下一次 hhmm 对应的时间戳（已过则取明天）
sch_cron_match(expr, now) / sch_cron_next(expr, now)当前时刻是否匹配 cron / 下次匹配时间戳
sch_now() / sch_hhmm_to_sec(hhmm)当前时间戳 / "HH:MM" 转当日秒数

cron 表达式（5 段，空格分隔）：分(0-59) 时(0-23) 日(1-31) 月(1-12) 周(0-7，0/7=周日)；字段支持 *、数字、a-b、*/n、a-b/n、逗号列表（如 0,15,30,45）。

import "sched" from "./hone_lib/sched.hn";

tasks = [
    sch_every(60, "hone backup.hn", "backup"),          // 每分钟备份
    sch_at("09:30", "hone report.hn", "daily-report"),  // 每天 9:30
    sch_cron("0 2 * * 1", "hone cleanup.hn", "weekly"), // 每周一凌晨 2 点
];
sch_run(tasks, 0);   // 一直运行，Ctrl+C 退出

值语义注意：Hone 列表/字典为值类型且不支持字段赋值（obj.f = v）， sch_run / sch_tick 会重建任务列表并返回，调用方需重新赋值 tasks = sch_run(tasks, 30)。测试脚本见 examples/test_sched_lib.hn。

#10. img 图片模块

图片标准库（纯 Hone 编写）：像素网格 + 绘图/滤镜/变换 + PPM P3 / SVG 读写。 图像表示为 dict {"w": 宽, "h": 高, "rows": [[[r,g,b],...],...]}， rows[y][x] 为像素（各通道 0-255，原点在左上角）。 Hone 的 str 无法承载二进制，故采用文本格式：PPM P3（ASCII 光栅，GIMP/ImageMagick 可查看）与 SVG（文本矢量，浏览器直接打开），不支持 PNG/BMP。 列表为值类型、索引赋值整体拷贝，绘图/滤镜适合 ≤128×128 的小图。

函数说明
img_new(w, h, r, g, b) / img_fill(img, r, g, b)新建 w×h 画布（填充色）/ 全图填充，返回新图像
img_get(img, x, y) / img_set(img, x, y, r, g, b)取像素 [r,g,b]（越界返回黑）/ 设像素（越界忽略）
img_size(img)图像尺寸 → [宽, 高]
img_rect(img, x0, y0, x1, y1, r, g, b) / img_line(img, x0, y0, x1, y1, r, g, b)实心矩形（自动裁剪到画布内）/ 直线（Bresenham）
img_circle(img, cx, cy, rad, r, g, b)实心圆（距离平方比较，rad≤0 画单点）
img_gradient_h(img, c1, c2) / img_gradient_v(img, c1, c2)水平 / 垂直渐变（c1、c2 为 [r,g,b] 列表）
img_checker(img, cell, c1, c2) / img_noise(img)棋盘格（cell 为格边长）/ 随机噪点
img_grayscale(img) / img_invert(img) / img_brightness(img, delta)灰度 / 反色 / 亮度调整（±255，自动裁剪）
img_contrast(img, factor) / img_threshold(img, t)对比度（float factor，1 不变）/ 二值化（亮度 < t 置黑）
img_flip_h(img) / img_flip_v(img) / img_rotate90(img)水平镜像 / 垂直镜像 / 顺时针旋转 90°
img_crop(img, x0, y0, x1, y1) / img_scale(img, nw, nh)裁剪区域 / 最近邻缩放
img_to_ppm(img) / img_save_ppm(img, path)转 PPM P3 文本 / 保存为 .ppm 文件
img_from_ppm(text) / img_load_ppm(path)解析 PPM P3 文本 / 读取 .ppm 文件 → 图像
img_to_svg(img, scale) / img_save_svg(img, path, scale)转 SVG 文本（每像素一个 rect，scale 为放大倍数）/ 保存为 .svg
import "img" from "./hone_lib/img.hn";

im = img_new(64, 64, 255, 255, 255);         // 白色画布
im = img_rect(im, 8, 8, 40, 40, 255, 0, 0);  // 红色实心矩形
im = img_circle(im, 32, 32, 16, 0, 0, 255);  // 蓝色实心圆
im = img_grayscale(im);                          // 灰度滤镜
img_save_ppm(im, "out.ppm");                    // 保存 PPM P3
img_save_svg(im, "out.svg", 4);              // 保存 SVG（每像素放大 4 倍）

测试脚本见 examples/test_img_lib.hn（35 项断言，生成 examples/img_test.ppm 与 examples/img_test.svg，浏览器打开 SVG 可预览）。
