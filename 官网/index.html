#为什么选择 Zap

🧰 极简无前缀

变量不需要 let / var / const：x = 10; 自动推导类型，零冗余。

🔒 静态强类型

类型一经推导即锁定，禁止隐式转换，报错精准（error[Z001] 格式 + 行列定位 + 修复建议）。

📦 单文件分发

下载 → 解压 → 运行，零配置。跨 Windows / Linux / macOS / Android（Termux）。

🛠 内置工具箱

文件、HTTP、JSON、时间、随机、字符串、数学、系统 API 开箱即用。
新增：日志、路径、参数解析、环境变量、键值存储、正则、哈希、UUID、时间解析。

🧩 集合类型

列表 [1, 2, 3]、字典 {"k": v} 开箱即用：for-in 遍历、f"..." 字符串插值、append / contains / keys / values 等集合函数。

⚡ 多线程与调试

go task(1); 一行启动线程；breakpoint; 断点；debug_print 调试输出；tmp fn 临时函数开发时自动忽略。

🔌 可嵌入可扩展

@export 打包 C ABI 动态库（DLL/SO/DYLIB）、load 动态库调用、import 远程模块、LSP 语言服务器。

#快速开始

下载 zap 可执行文件（或 cargo build --release 自行构建），然后：

// hello.zp
print("Hello Zap!");

// 变量与类型
x = 10;              // 自动推导为 int
y : int = 20;    // 显式类型
print(x + y);       // 30

// 递归函数
fn fib(n) {
    if (n <= 1) { return n; }
    return fib(n - 1) + fib(n - 2);
}
print(fib(10));   // 55

命令行工具链（全部集成在单文件 zap / zap.exe 中）：

命令功能
zap run <script.zp>执行脚本（默认命令）
zap debug <script.zp>断点调试（breakpoint 生效）
zap fmt [-w] <file.zp>代码格式化（Tab 缩进/运算符空格/大括号）
zap build --dll <file.zp>打包 C ABI 动态库（int/float/bool/str 类型映射）
zap get <module> <url>下载模块依赖并缓存
zap upgrade [-w] <file.zp>按映射表迁移旧版本语法
zap lsp语言服务器（补全/诊断/hover）
zap poop <file.zp>屎山检测——分析 if 嵌套深度和圈复杂度

#路线图

  • ✅ 阶段 1：核心执行器（词法 / 解析 / AST / 解释器 / 静态类型检查）
  • ✅ 阶段 2：fmt、debug、go 多线程、sys Windows API、build --dll（int/float/bool/str）
  • ✅ 阶段 3：import 远程模块、load lazy、use / alias、zap get、upgrade、lsp、可视化编辑器
  • ✅ 阶段 4：GitHub 开源、独立官网、--dll 全类型映射、zap poop 屎山检测
  • 🚧 阶段 5：内置函数扩展（log/path/args/env/db/regex/crypto）、tmp fn、debug_print、import as、try/catch/throw、--restart/--resume、build --exe、zap explain
  • 🚧 阶段 6：集合类型（列表/字典）、for-in 循环、f-string 插值、类型判断、time.parse、uuid.new
