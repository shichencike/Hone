#下载中心

Hone 是单文件可执行程序：下载 → 解压 → 运行，零依赖、零配置。当前最新版本 v0.6.0。 国内用户无需加速器：直接点下方「国内镜像」按钮，走清华 TUNA 镜像高速下载，与官方 GitHub 文件完全一致（sha256 相同）。

直接下载

🪟 Windows x86_64
hone-windows-x86_64.exe
64 位 Windows 10 / 11，无需安装，双击或命令行直接运行
国内镜像 GitHub 官方
🐧 Linux x86_64
hone-linux-x86_64
musl 静态编译，不依赖系统 glibc，任何发行版直接运行
国内镜像 GitHub 官方
🤖 Termux（Android）
hone-termux-aarch64
Termux 终端环境（ARM64），静态编译开箱即用
国内镜像 GitHub 官方
校验和：每次发布附带 checksums.txt（镜像） / GitHub， 用 sha256sum（Windows 用 Get-FileHash -Algorithm SHA256）比对下载文件的哈希。 全部历史版本见 GitHub Releases。

一键脚本安装（推荐）

脚本会自动下载对应平台二进制、校验 sha256 并安装，无需手动管理文件。国内用户可直接从镜像拉取脚本（无需加速器）：

// Linux / Termux（镜像拉取，国内直连）
curl -fsSL https://mirrors.tuna.tsinghua.edu.cn/github-release/shichencike/Hone/releases/latest/download/install.sh | sh

// Windows（PowerShell 5.1+，镜像拉取）
irm https://mirrors.tuna.tsinghua.edu.cn/github-release/shichencike/Hone/releases/latest/download/install.ps1 | iex

// 或从 GitHub 官方拉取（脚本内部默认已走镜像、失败自动回退官方）
curl -fsSL https://github.com/shichencike/Hone/releases/latest/download/install.sh | sh
irm https://github.com/shichencike/Hone/releases/latest/download/install.ps1 | iex

指定版本：HONE_VERSION=v0.6.0 curl -fsSL .../install.sh | sh（Windows 先 $env:HONE_VERSION = "v0.6.0"）。详细说明见 安装教程。

镜像源（国内加速）：安装脚本默认先走清华 TUNA github-release 镜像，失败自动回退官方 GitHub； 可用 HONE_MIRROR 指定其他镜像，或 HONE_MIRROR=off 强制只用官方源。 hone self-update 更新命令同样支持（默认镜像优先、自动回退）。

源码构建

需要 Rust 工具链（rustc ≥ 1.71）：

git clone https://github.com/shichencike/Hone.git
cd Hone
cargo build --release
// 产物: target/release/hone（Windows 为 target/release/hone.exe）
./target/release/hone --version
