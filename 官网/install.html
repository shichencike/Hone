#安装教程

Hone 是单文件可执行程序：一行命令安装，零依赖、零配置。选择你的方式：

  1. 一键脚本安装（推荐）
  2. 手动下载（GitHub Releases）
  3. 源码构建
  4. 验证安装

#1. 一键脚本安装（推荐）

Linux / Termux（Android）

curl -fsSL https://github.com/shichencike/Hone/releases/latest/download/install.sh | sh

脚本自动识别平台（x86_64 → hone-linux-x86_64；aarch64 / Termux → hone-termux-aarch64），优先下载 .tar.gz 压缩包（体积更小），校验 sha256 后原子安装：Linux 默认装到 ~/.hone/bin（Termux 下自动装到 $PREFIX/bin）并自动写入 shell 配置加入 PATH。

脚本支持断点续传与失败重试；已安装相同版本（哈希一致）时自动跳过下载；HONE_UNINSTALL=1 可一键卸载（删除二进制与 PATH 配置）。

Windows（PowerShell 5.1+）

irm https://github.com/shichencike/Hone/releases/latest/download/install.ps1 | iex

优先使用系统自带的 curl.exe 下载（更快、支持续传与重试），强制 TLS 1.2，安装到 %LOCALAPPDATA%\hone\bin 并幂等加入用户 PATH（新开的终端生效）；HONE_UNINSTALL=1 可卸载。

指定版本：HONE_VERSION=v0.6.1 curl -fsSL https://github.com/shichencike/Hone/releases/latest/download/install.sh | sh（Windows 同理，先 $env:HONE_VERSION = "v0.6.1"）。

镜像源（国内加速）：脚本默认先走ghproxy.net 前缀代理，失败自动回退官方 GitHub，无需任何配置。 也可用环境变量 HONE_MIRROR 指定其他镜像，或设 HONE_MIRROR=off 强制只用官方源：

# 直接从镜像拉取脚本（国内直连，无需加速器）
curl -fsSL https://ghproxy.net/https://github.com/shichencike/Hone/releases/latest/download/install.sh | sh
# Windows 同理：直接从镜像拉取脚本
irm https://ghproxy.net/https://github.com/shichencike/Hone/releases/latest/download/install.ps1 | iex
# 指定镜像（任意前缀，自动拼官方完整路径，ghproxy.net 前缀代理结构）
HONE_MIRROR=https://ghproxy.net/ curl -fsSL .../install.sh | sh
# 强制只用官方 GitHub（不走镜像）
HONE_MIRROR=off curl -fsSL .../install.sh | sh

#2. 手动下载（GitHub Releases）

从 GitHub Releases 下载对应平台的可执行文件（每次发布同时附带 checksums.txt 供 sha256 校验）：

平台文件说明
Windows x86_64hone-windows-x86_64.exe64 位 Windows 10 / 11
Linux x86_64hone-linux-x86_64musl 静态编译，任何发行版直接运行
Termux（Android）hone-termux-aarch64Termux 终端环境（ARM64）

Linux / Termux 版为静态编译，不依赖系统 glibc / bionic，开箱即用。

#3. 源码构建

需要 Rust 工具链（rustc ≥ 1.71）。

git clone https://github.com/shichencike/Hone.git
cd Hone
cargo build --release
// 产物: target/release/hone（Windows 为 target/release/hone.exe）
./target/release/hone --version    // hone 0.4.0

#4. 验证安装

// hello.hn
print("Hello, Hone!");

// 运行脚本
hone hello.hn    // Hello, Hone!

安装完成！下一步：阅读语言手册 或 查看示例。
