#安装教程

Hone 是单文件可执行程序：一行命令安装，零依赖、零配置。选择你的方式：

  1. 一键脚本安装（推荐）
  2. 包管理器安装（Homebrew / Scoop）
  3. 手动下载（GitHub Releases）
  4. 源码构建
  5. 验证安装

#1. 一键脚本安装（推荐）

Linux / Termux（Android）

curl -fsSL https://github.com/shichencike/Hone/releases/latest/download/install.sh | sh

脚本自动识别平台（x86_64 → hone-linux-x86_64；aarch64 / Termux → hone-termux-aarch64），下载后校验 sha256 并安装到 ~/.hone/bin。

Windows（PowerShell 5.1+）

irm https://github.com/shichencike/Hone/releases/latest/download/install.ps1 | iex

安装到 %LOCALAPPDATA%\hone\bin 并自动加入用户 PATH（新开的终端生效）。

指定版本：HONE_VERSION=v0.3.0 curl -fsSL https://github.com/shichencike/Hone/releases/latest/download/install.sh | sh（Windows 同理，先 $env:HONE_VERSION = "v0.3.0"）。

#2. 包管理器安装

Homebrew（Linux）

brew tap shichencike/homebrew-hone
brew install hone

新版本发布后 brew upgrade hone 即可更新。

Scoop（Windows）

scoop bucket add hone https://github.com/shichencike/scoop-hone
scoop install hone

新版本发布后 scoop update hone 即可更新（manifest 配置了自动更新）。

macOS 版暂未发布，Homebrew 安装目前面向 Linux；Windows 用户优先推荐脚本或 Scoop 安装。

#3. 手动下载（GitHub Releases）

从 GitHub Releases 下载对应平台的可执行文件（每次发布同时附带 checksums.txt 供 sha256 校验）：

平台文件说明
Windows x86_64hone-windows-x86_64.exe64 位 Windows 10 / 11
Linux x86_64hone-linux-x86_64musl 静态编译，任何发行版直接运行
Termux（Android）hone-termux-aarch64Termux 终端环境（ARM64）

Linux / Termux 版为静态编译，不依赖系统 glibc / bionic，开箱即用。

#4. 源码构建

需要 Rust 工具链（rustc ≥ 1.71）。

git clone https://github.com/shichencike/Hone.git
cd Hone
cargo build --release
// 产物: target/release/hone（Windows 为 target/release/hone.exe）
./target/release/hone --version    // hone 0.3.0

#5. 验证安装

// hello.hn
print("Hello, Hone!");

// 运行脚本
hone hello.hn    // Hello, Hone!

安装完成！下一步：阅读语言手册 或 查看示例。
