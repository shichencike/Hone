#变量与类型系统

静态强类型：类型一经推导或显式声明即锁定，禁止隐式转换。

x = 10;              // 自动推导为 int
f = 3.14;            // 自动推导为 float
y : int = 20;    // 显式类型（Rust/TS 风格）
int z = 30;      // 显式类型（C 风格）
x = "Zap";          // error[Z001]: 期望 int，得到 str
类型说明字面量示例
int64 位有符号整数0, 42, -1
float64 位双精度（IEEE 754）3.14, .2, 2.0
bool布尔值true, false
strUTF-8 字符串"hello"（支持 \n \t \\ \"）
list动态列表（元素类型不锁定）[1, "a", true]
dict动态字典（字符串键 → 任意值）{"name": "zap", "ver": 1}

#控制流

条件表达式必须显式返回 bool，禁止隐式转换（if (1) 视为非法）。

if (x > 5) {
    print("大");
} else if (x > 0) {
    print("小");
} else {
    print("非正");
}

i = 0;
while (i < 10) {
    i = i + 1;
}

// for-in：遍历列表（单变量）或字典（键、值双变量）
nums = [1, 2, 3];
for x in nums {
    print(x * x);      // 1 4 9
}

user = {"name": "zap", "ver": 1};
for k, v in user {
    print(k + "= " + to_str(v));
}

#函数定义

fn add(a : int, b : int) -> int {
    return a + b;
}

// 参数类型可由调用上下文推导（推荐复杂场景显式声明）
fn greet(name) {
    print("你好, " + name);
}
  • 函数返回类型由 return 推导，也可用 fn f() -> type 声明
  • 无返回值时调用作为表达式得到 null 占位
  • 所有函数扁平化存在于全局符号表（不支持 :: 路径）

#集合与字符串插值

列表 [a, b, c] 与字典 {"k": v} 为动态集合类型：元素类型不锁定、可混合， 变量本身仍遵循类型锁定规则（不能把列表赋给已锁定的标量变量）。

nums = [1, "a", true];          // 混合元素列表
user = {"name": "zap", "ver": 1};   // 字符串键 → 任意值

print(len(nums));               // 3（元素个数）
print(to_str(user));            // {name: zap, ver: 1}

l = append(nums, "x");          // [1, a, true, x]（返回新列表）
print(contains(l, "a"));       // true
print(index_of(l, "x"));       // 3（找不到返回 -1）

print(has_key(user, "name"));  // true
print(to_str(keys(user)));      // [name, ver]
print(to_str(values(user)));    // [zap, 1]

f-string 字符串插值：f"..." 内 {expr} 嵌入任意表达式， {{ / }} 转义字面大括号：

name = "zap";
print(f"你好, {name}! sum = {1 + 2}");   // 你好, zap! sum = 3
print(f"{{{1 + 1}}}");                 // 字面大括号 + 表达式

类型判断：is_int is_float is_str is_bool is_list is_dict is_null，判断运行期值类型，常用于分支处理混合集合。

#导入与外部集成

// import：远程模块下载并缓存到 ~/.zap/cache/
import "math_mod" from "http://example.com/math_mod.zp";
 print(module_add(20, 22));

 // import as：以别名导入，函数名前缀自动替换
 import "math_mod" from "http://example.com/math_mod.zp" as m;
 print(m_add(20, 22));

 // load：动态库加载（C ABI，int64 参数/返回值）
 load "path/to/zap_lib.dll" as m;
 print(m.lib_add(1, 2));

 // load lazy：懒加载，首次调用时才加载
 load lazy "path/to/zap_lib.dll" as lm;

 // alias：函数别名
 alias greet as hi;

 // tmp fn：临时函数，编译自动忽略
 tmp fn helper() { print("debug"); }

 // debug_print：调试输出，仅 zap debug 模式生效
 debug_print("x = " + to_str(x));

#工具链

命令说明
zap run <script.zp>执行脚本（默认命令）
zap run --restart[=N] <script.zp>失败自动重启；--backoff=a,b,c 间隔递增，--restart-on=Zxxx 错误码白名单
zap run --resume <script.zp>恢复 db 检查点继续执行（db.set 自动落盘，脚本变更后检查点失效）
zap debug <script.zp>断点调试：breakpoint 打印变量快照，等待 Enter 继续
zap fmt [-w] <file.zp>代码格式化（Tab 缩进、运算符空格、大括号位置）
zap build --dll <file.zp>打包 C ABI 动态库；类型映射 int→int64_t、float→double、bool→bool、str→const char*；需系统 C 编译器
zap build --exe <file.zp>打包独立可执行文件（解释器+脚本自释放，[-o <out>]）；打包后 --version 查看版本信息，--keep-cache 保留缓存
zap explain <code>查看错误码解释与修复建议（如 zap explain Z201）
zap get <module> <url>下载模块依赖并缓存到 ~/.zap/cache/（也支持扫描脚本 import 批量预下载）
zap upgrade [-w] <file.zp>按映射表自动迁移旧版本语法
zap lsp语言服务器（补全/诊断/hover，LSP over stdio）
zap poop <file.zp>屎山检测——分析 if 嵌套深度和圈复杂度

  --> err.zp:3:1
3 | x = "Zap";
  | ^

错误码含义
Z001 ~ Z012类型 / 语法 / 推导 / 运行期基础错误
Z101 ~ Z104词法语法细分：非法字符 / 未闭合字符串 / 未闭合注释 / 缺少分号
Z200 ~ Z204网络：请求失败 / 超时 / 连接拒绝 / DNS 失败 / 非 2xx 响应
Z300 ~ Z303系统 / DLL：系统调用 / 库加载失败 / 参数校验 / 权限不足
Z401 ~ Z404文件：不存在 / 权限不足 / 被占用锁定 / 通用 NOT_FOUND
Z600throw 主动抛出的用户错误
Z999尚未实现

完整解释与修复建议：zap explain Z201。

#错误处理与恢复

try-catch 捕获可恢复错误（ZError 通道）；内存越界等 panic 类崩溃不进入捕获，保持原有崩溃行为。配合 --restart / --resume 实现无人值守运行。

try {
    resp = http_get("http://example.com/data");
} catch e {
    print(e.code + ": " + e.message);  // 字段: code/message/file/line/col/context
    resp = db.get("cached");        // 降级回退
}

throw "用户错误";   // 主动抛出 → error[Z600]
throw e;             // 重抛已捕获的 error 值
机制说明
--restart[=N]脚本失败自动重拉（默认最多 3 次）；--backoff=a,b,c 重启间隔递增（默认 1,3,10 秒）；--restart-on=Z200,Z401 只对白名单错误码重启，确定性错误直接退出
--resume恢复上次 db 检查点；db.set 自动落盘 ~/.zap/state/，崩溃不丢检查点，脚本内容变更后检查点自动失效
错误对象字段e.code / e.message / e.file / e.context（str）；e.line / e.col（int）

注意：Zap 为块作用域，try/catch 块内赋值的变量在块外不可见，跨块共享的变量需在块前声明。示例见 examples/try_catch.zp、examples/restart_demo.zp、examples/resume_demo.zp。

#设计原则

  • 不自举：Zap 不用于开发自己的编译器，保持设计与实现的灵活性
  • 不背兼容包袱：旧版本永久可用，新版本自由演化（提供 upgrade 迁移工具）
  • 无前缀声明：变量不需要 let / var / const
  • 静态强类型：类型锁定，不隐式转换，报错精准
  • 单文件分发：下载 → 解压 → 运行，零配置；多版本共存互不干扰
