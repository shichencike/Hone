#语法风格

项目约定
文件扩展名.zp
语句结束符; 分号
代码块{ } 大括号
缩进强制 Tab（zap fmt 统一）
注释// 单行 与 /* 多行 */
命名空间点号访问：time.now()、sys.msgbox()
临时函数tmp fn name() { ... } 编译自动忽略
调试输出debug_print(expr); 仅 debug 模式生效

#变量与类型系统

静态强类型：类型一经推导或显式声明即锁定，禁止隐式转换。

x = 10;              // 自动推导为 int
f = 3.14;            // 自动推导为 float
y : int = 20;    // 显式类型（Rust/TS 风格）
int z = 30;      // 显式类型（C 风格）
x = "Zap";          // error[Z001]: 期望 int，得到 str
类型说明字面量示例
int64 位有符号整数0, 42, -1
float64 位双精度（IEEE 754）3.14, .2, 2.0
bool布尔值true, false
strUTF-8 字符串"hello"（支持 \n \t \\ \"）

#控制流

条件表达式必须显式返回 bool，禁止隐式转换（if (1) 视为非法）。

if (x > 5) {
    print("大");
} else if (x > 0) {
    print("小");
} else {
    print("非正");
}

i = 0;
while (i < 10) {
    i = i + 1;
}

#函数定义

fn add(a : int, b : int) -> int {
    return a + b;
}

// 参数类型可由调用上下文推导（推荐复杂场景显式声明）
fn greet(name) {
    print("你好, " + name);
}
  • 函数返回类型由 return 推导，也可用 fn f() -> type 声明
  • 无返回值时调用作为表达式得到 null 占位
  • 所有函数扁平化存在于全局符号表（不支持 :: 路径）

#导入与外部集成

// import：远程模块下载并缓存到 ~/.zap/cache/
import "math_mod" from "http://example.com/math_mod.zp";
 print(module_add(20, 22));

 // import as：以别名导入，函数名前缀自动替换
 import "math_mod" from "http://example.com/math_mod.zp" as m;
 print(m_add(20, 22));

 // load：动态库加载（C ABI，int64 参数/返回值）
 load "path/to/zap_lib.dll" as m;
 print(m.lib_add(1, 2));

 // load lazy：懒加载，首次调用时才加载
 load lazy "path/to/zap_lib.dll" as lm;

 // alias：函数别名
 alias greet as hi;

 // tmp fn：临时函数，编译自动忽略
 tmp fn helper() { print("debug"); }

 // debug_print：调试输出，仅 zap debug 模式生效
 debug_print("x = " + to_str(x));

#工具链

命令说明
zap run <script.zp>执行脚本（默认命令）
zap debug <script.zp>断点调试：breakpoint 打印变量快照，等待 Enter 继续
zap fmt [-w] <file.zp>代码格式化（Tab 缩进、运算符空格、大括号位置）
zap build --dll <file.zp>打包 C ABI 动态库；类型映射 int→int64_t、float→double、bool→bool、str→const char*；需系统 C 编译器
zap get <module> <url>下载模块依赖并缓存到 ~/.zap/cache/（也支持扫描脚本 import 批量预下载）
zap upgrade [-w] <file.zp>按映射表自动迁移旧版本语法
zap lsp语言服务器（补全/诊断/hover，LSP over stdio）
zap poop <file.zp>屎山检测——分析 if 嵌套深度和圈复杂度

#错误报告与错误码

error[Z001]: type mismatch: variable `x` is locked to `int`, got `str`
  --> err.zp:3:1
3 | x = "Zap";
  | ^
help: Zap types are locked after inference; no implicit conversion is allowed
错误码含义
Z001类型冲突（期望 X，得到 Y）
Z002未定义的变量或函数
Z003无法自动推导类型，请添加显式类型
Z004运算符重载歧义
Z005语法错误
Z006 / Z007字符串转整数 / 浮点数失败
Z008条件表达式必须是 bool
Z009 / Z010除零 / 整数溢出
Z011 / Z012参数数量不匹配 / 递归过深
Z200 / Z300网络请求失败 / 系统调用失败
Z404文件或库不存在
Z999尚未实现

#设计原则

  • 不自举：Zap 不用于开发自己的编译器，保持设计与实现的灵活性
  • 不背兼容包袱：旧版本永久可用，新版本自由演化（提供 upgrade 迁移工具）
  • 无前缀声明：变量不需要 let / var / const
  • 静态强类型：类型锁定，不隐式转换，报错精准
  • 单文件分发：下载 → 解压 → 运行，零配置；多版本共存互不干扰
