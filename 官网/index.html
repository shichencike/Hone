#为什么选择 Hone

🧰 极简无前缀

变量不需要 let / var / const：x = 10; 自动推导类型，零冗余。

🔒 静态强类型

类型一经推导即锁定，禁止隐式转换，报错精准（error[H001] 格式 + 行列定位 + 修复建议）。

📦 单文件分发

下载 → 解压 → 运行，零配置。跨 Windows / Linux / macOS / Android（Termux）。

🛠 内置工具箱

文件、HTTP、JSON、时间、随机、字符串、数学、系统 API 开箱即用。
新增：日志、路径、参数解析、环境变量、键值存储、正则、哈希、UUID、时间解析、标准输入（input / read_int / read_float）。

🧩 集合类型

列表 [1, 2, 3]、字典 {"k": v} 开箱即用：for-in 遍历、f"..." 字符串插值、append / contains / keys / values 等集合函数。

⚡ 多线程与调试

go task(1); 一行启动线程；breakpoint; 断点；debug_print 调试输出；tmp fn 临时函数开发时自动忽略。

🔌 可嵌入可扩展

@export 打包 C ABI 动态库（DLL/SO/DYLIB）、load 动态库调用、import 远程模块、LSP 语言服务器。 模块清单 hone.json 一条命令拉齐全部依赖（类似 package.json / Cargo.toml）。

🏷 class 类与泛型

class Math { fn double(x) {...} } 类成员函数不进全局符号表，经 类.方法(...) 调用； fn identity[T](x: T) -> T 泛型函数按实参自动推导，编译期擦除、运行期零成本。

🧪 新语法 v0.6.3

continue、C 风格 for (init; cond; step)、do-while、 复合赋值 += -= *= /= %=、自增自减 ++ --、 三元 cond ? a : b、空值合并 a ?? b、 匿名函数 lambda（一等值/闭包）、函数默认参数、三引号原始字符串 """..."""。

🖥 图形界面库

纯 Hone 编写的跨平台 GUI（hone_lib/gui.hn）：浏览器渲染 + 本地 HTTP 服务器双向交互，button / label / input / select 控件开箱即用。

🎵 音乐理论库

纯 Hone 编写的乐理标准库（hone_lib/music.hn）：音名 ↔ MIDI ↔ 频率换算、音阶与和弦生成、时值与 BPM、音程与移调、调号与调性、顺阶和声，开箱即用。

🐱 桌宠标准库

Windows 桌面宠物库（hone_lib/pet.hn）：Hone 驱动状态机 + PowerShell 透明置顶窗，内置像素猫动画、说话气泡、点击/拖拽交互、右键菜单，开箱即用（hone examples/pet_demo.hn）。

🪟 原生图形界面库

原生窗口 + 原生控件标准库（hone_lib/guipro.hn，gui.hn 的升级版）：Windows 用 Win32 标准控件、Linux 动态加载 GTK3，button / label / input / select / checkbox / radio + 闭包事件分发 + 定时器 + 消息框，开箱即用（hone examples/guipro_demo.hn）。

#快速开始

安装 hone（一键脚本，或 cargo build --release 自行构建），然后：

// hello.hn
print("Hello Hone!");

// 变量与类型
x = 10;              // 自动推导为 int
y : int = 20;    // 显式类型
print(x + y);       // 30

// 递归函数
fn fib(n) {
    if (n <= 1) { return n; }
    return fib(n - 1) + fib(n - 2);
}
print(fib(10));   // 55

命令行工具链（全部集成在单文件 hone / hone.exe 中）：

命令功能
hone run <script.hn>执行脚本（默认命令）
hone debug <script.hn>断点调试（breakpoint 生效）
hone fmt [-w] <file.hn>代码格式化（Tab 缩进/运算符空格/大括号）
hone build --dll <file.hn>打包 C ABI 动态库（int/float/bool/str 类型映射）
hone build --exe <file.hn>打包独立可执行文件（解释器+脚本自释放）
hone bind <header.h>从 C 头文件生成 typed load 签名块（FFI 自动绑定）
hone explain <code>查询错误码含义与修复建议
hone get读取 hone.json 清单批量下载模块（类似 package.json / Cargo.toml）
hone get <module> <url>下载模块依赖并缓存，同时写入 hone.json 清单
hone test [目录]扫描并运行 *.test.hn 测试（配合 assert 断言，汇总 PASS/FAIL）
hone build --script <file.hn>生成仅脚本压缩包 .hzp（不内嵌解释器，用 hone run 执行）
hone self-update [url]下载最新 hone 二进制并替换当前程序
hone lsp语言服务器（补全/诊断/hover）
hone repl交互式解释器（Python 式：表达式回显 / 多行续行 / .vars 查看变量）
hone prof <file.hn>剖析模式运行，输出函数级热点报告（总耗时/调用次数/平均耗时）
hone poop <file.hn>屎山检测——分析 if 嵌套深度和圈复杂度

#路线图

  • ✅ 阶段 1：核心执行器（词法 / 解析 / AST / 解释器 / 静态类型检查）
  • ✅ 阶段 2：fmt、debug、go 多线程、sys Windows API、build --dll（int/float/bool/str）
  • ✅ 阶段 3：import 远程模块、load lazy、use / alias、hone get、lsp、可视化编辑器
  • ✅ 阶段 4：GitHub 开源、独立官网、--dll 全类型映射、hone poop 屎山检测
  • ✅ 阶段 5：内置函数扩展（log/path/args/env/db/regex/crypto）、tmp fn、debug_print、import as、try/catch/throw、--restart/--resume、build --exe、hone explain
  • ✅ 阶段 6：集合类型（列表/字典）、for-in 循环、f-string 插值、类型判断、time.parse、uuid.new
  • ✅ 阶段 7：本地 HTTP 服务器（server.listen / server.poll / server.respond）、hone_lib 图形界面库（浏览器渲染 + 双向交互）
  • ✅ 阶段 8：typed FFI 签名块（int/float/bool/str/ptr/void 精确类型映射）、头文件自动绑定（from "header.h"）、hone bind 离线生成签名
  • ✅ 阶段 9：struct 结构体、match 模式匹配、|> 管道操作符、hone test 测试框架、build --script 仅脚本包、self-update 自动更新
  • ✅ 阶段 10：crypto 扩展（sha1/HMAC/base64）、archive 压缩归档（zip/tar.gz）、ptr 指针类（防野指针）、plugin 插件系统
