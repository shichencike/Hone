#安装教程

Zap 是单文件可执行程序：下载 → 解压 → 运行，零依赖、零配置。选择你的平台：

  1. 下载二进制
  2. Windows
  3. Linux
  4. Termux（Android）
  5. 源码构建
  6. 验证安装

#1. 下载二进制

从 GitHub Releases 下载对应平台的 zap 可执行文件：

平台文件说明
Windows x86_64zap-windows-x86_64.exe64 位 Windows 10 / 11
Linux x86_64zap-linux-x86_64musl 静态编译，任何发行版直接运行
Termux（Android）zap-termux-aarch64Termux 终端环境（ARM64）

Linux / Termux 版为静态编译，不依赖系统 glibc / bionic，开箱即用。

#2. Windows

// 1. 下载 zap-windows-x86_64.exe，重命名为 zap.exe
mkdir C:\zap
copy zap-windows-x86_64.exe C:\zap\zap.exe

// 2. 验证
C:\zap\zap.exe --version    // zap 0.2.0

// 3.（可选）加入 PATH，任意目录直接使用 zap 命令
setx PATH "%PATH%;C:\zap"

#3. Linux

// 1. 下载并赋予执行权限
wget https://github.com/shichencike/zap/releases/download/v0.2.0/zap-linux-x86_64
chmod +x zap-linux-x86_64

// 2. 放入 PATH 目录
sudo mv zap-linux-x86_64 /usr/local/bin/zap

// 3. 验证
zap --version    // zap 0.2.0

#4. Termux（Android）

// 1. 安装 Termux（F-Droid 商店）并打开终端

// 2. 下载 zap-termux-aarch64
curl -L -o zap https://github.com/shichencike/zap/releases/download/v0.2.0/zap-termux-aarch64

// 3. 赋予执行权限并放入 PATH
chmod +x zap
mv zap $PREFIX/bin/zap

// 4. 验证
zap --version    // zap 0.2.0

#5. 源码构建

需要 Rust 工具链（rustc ≥ 1.71）。

git clone https://github.com/shichencike/zap.git
cd zap
cargo build --release
// 产物: target/release/zap（Windows 为 target/release/zap.exe）
./target/release/zap --version    // zap 0.2.0

#6. 验证安装

// hello.zp
print("Hello, Zap!");

// 运行脚本
zap hello.zp    // Hello, Zap!

安装完成！下一步：阅读语言手册 或 查看示例。
