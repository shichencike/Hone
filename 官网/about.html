#关于 Hone

Hone 是一门轻量级、跨平台、可嵌入的脚本语言，用 Rust 实现，单文件可执行程序，开箱即用。 项目始于对「少依赖、快上手」的追求：下载一个文件就能跑脚本，内置常用的系统能力，没有繁琐的环境配置。

设计理念

⚡ 为效率而生

无前缀变量声明、静态强类型编译期报错、内置文件/HTTP/JSON/多线程等工具箱，脚本即写即跑。

📦 单文件分发

下载 → 解压 → 运行，零配置、零依赖，跨 Windows / Linux / Termux，多版本共存互不干扰。

🛠 可嵌入可扩展

@export 打包 C ABI 动态库、typed FFI 调用 C 库、load 动态库、plugin 插件系统（运行期动态注册）、import 远程模块、LSP 语言服务器。

🧰 现代语言特性

struct 结构体（确定数据形态）、match 模式匹配、|> 管道操作符、深度拷贝 clone/copy、指针类 ptr.*（分配表跟踪防野指针）。

🧩 工具箱全开

crypto 加密哈希（md5/sha1/sha256/HMAC/base64）、archive 压缩归档（zip/tar.gz）、server 本地 HTTP 服务器、hone test 测试框架。

🔒 严谨而不繁琐

类型一经推导即锁定，禁止隐式转换；错误码（Hxxx）+ 行列定位 + 修复建议，让报错可读、可查、可修。

🧩 不背兼容包袱

旧版本永久可用，新版本自由演化，升级不背兼容包袱。

🗡️ 为乐趣而造

也提供 hone poop 屎山检测、可视化编辑器（editor/index.html）这类开发乐趣工具。

路线图

  • ✅ 阶段 1：核心执行器（词法 / 解析 / AST / 解释器 / 静态类型检查）
  • ✅ 阶段 2：fmt、debug、go 多线程、sys Windows API、build --dll
  • ✅ 阶段 3：import 远程模块、load lazy、use / alias、hone get、lsp、可视化编辑器
  • ✅ 阶段 4：GitHub 开源、独立官网、--dll 全类型映射、hone poop
  • ✅ 阶段 5：内置函数扩展（log/path/args/env/db/regex/crypto）、tmp fn、try/catch/throw、--restart/--resume、build --exe、hone explain
  • ✅ 阶段 6：集合类型（列表/字典）、for-in、f-string、类型判断、time.parse、uuid.new
  • ✅ 阶段 7：本地 HTTP 服务器（server.*）、hone_lib 图形界面库
  • ✅ 阶段 8：typed FFI 签名块、头文件自动绑定（from "header.h"）、hone bind
  • ✅ 阶段 9：struct 结构体、match 模式匹配、|> 管道操作符、hone test 测试框架、build --script 仅脚本包、self-update 自动更新
  • ✅ 阶段 10：crypto 扩展（sha1/HMAC/base64）、archive 压缩归档（zip/tar.gz）、ptr 指针类（防野指针）、plugin 插件系统
