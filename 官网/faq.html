#常见问题

Hone 是什么？和 Python / Lua / JavaScript 有什么区别？
Hone 是用 Rust 实现的轻量级脚本语言：静态强类型（类型一经推导即锁定、禁止隐式转换）、 单文件分发（一个可执行程序开箱即用）、内置工具箱（文件 / HTTP / JSON / 时间 / 正则 / 哈希 / 多线程等零配置可用）。与解释型脚本语言相比，它在编译期就能报出类型错误，且不需要装运行时环境； 与 Rust / Go 相比，它没有编译与配置成本，适合快速脚本、自动化与胶水场景。
如何安装 Hone？支持哪些平台？
一行命令安装（详见安装教程）：Linux / Termux 用 curl -fsSL .../install.sh | sh，Windows 用 irm .../install.ps1 | iex；也可从 下载中心 手动下载 （Windows x86_64、Linux x86_64、Termux aarch64 三平台单文件二进制）。macOS 暂未发布。 所有版本都是静态编译，不依赖系统动态库，开箱即用。
为什么变量不需要 let / var / const？
Hone 采用无前缀声明：x = 10; 自动推导类型并锁定。 这是刻意的设计取舍——少写关键字、代码更简洁；类型一经锁定，后续赋值不同类型会直接报 error[H001]，编译期即可发现，并不比显式声明更危险。需要显式类型时可用 y : int = 20;（Rust/TS 风格）或 int z = 30;（C 风格）。
报错 error[Hxxx] 看不懂怎么办？
错误统一为 error[Hxxx] 格式，带文件、行、列与修复建议。用内置命令 hone explain H201 可查看错误码的完整含义与修复方法（如 H001 类型不匹配、 H005 参数个数错误、H200 网络错误、H401 文件不存在）。
脚本崩溃了如何自动恢复？
两条路线：hone run --restart=3 app.hn 失败自动重启（ --backoff=1,3,10 递增等待，--restart-on=H200,H401 只对白名单错误码重启）； hone run --resume app.hn 启用检查点恢复——db.set 自动落盘到 ~/.hone/state/，崩溃后从上次检查点继续，脚本内容变更后检查点自动失效。
能不能调用 C / C++ 写的库？
可以。v0.4.0 起支持 typed FFI：load "lib" as m { fn f(a: int) -> float; } 签名块显式声明 C ABI 类型（int/float/bool/str/ptr/void），调用时精确转换；还可 load "lib" as m from "header.h" 从 C 头文件自动提取原型生成签名，或用 hone bind header.h 离线生成。反之，用 @export + hone build --dll 也可把 Hone 函数打包成 C ABI 动态库供其他语言调用。
能写图形界面吗？
能。标准库自带 hone_lib/gui.hn：浏览器渲染 + 本地 HTTP 服务器双向交互的 跨平台 GUI（Windows / Linux / Termux 均有浏览器），button / label / input / select 控件开箱即用， 事件回调约定 on_event(id, value)。见 标准库文档 与 examples/gui_demo.hn。
能不能把脚本打包成独立的可执行文件？
可以。hone build --exe app.hn [-o my_app.exe] 把解释器与脚本打包为 自释放单文件，双击即用（运行后自动清理缓存，--keep-cache 可保留以加速下次启动）； --version 查看内嵌版本信息。
Hone 是开源的么？用什么许可证？
是的，源码托管在 github.com/shichencike/Hone， MIT 许可证，可自由使用、修改与分发。欢迎提交 issue 与 PR。
从哪里获得更新？有升级工具吗？
发布信息见 更新日志 与 GitHub Releases； hone self-update 可直接下载并替换最新版本。 设计上「旧版本永久可用、新版本自由演化」，升级不背兼容包袱。

语言陷阱（常见坑）

为什么 try/catch 块内声明的变量，块外访问报「未定义」？
Hone 是块作用域：try 体、catch 处理器各自是独立作用域， 块内声明的变量不会泄漏到块外，catch 绑定的 e 也只在 catch 块内有效。 需要跨块共享的变量请在 try 之前声明，块内只做赋值： 
x = 0;
try { x = to_int("42"); }
catch e { x = -1; }
print(x);   // 42
为什么 append 之后列表没变？
列表是值类型：append(list, x) 返回追加后的新列表，不会原地修改原列表。 必须把返回值赋回去：nums = append(nums, 4);。 clone / copy 同理是深拷贝，改副本不影响原值。
为什么 2 和 2.0 不能比较 / 混算？
字面量 2 是 int，2.0 才是 float。 Hone 禁止隐式转换（int↔float 也不行），混合运算或比较会报 error[H001]。需要时显式转换： to_float(x) / to_int(x)。
为什么 len("你好") 返回 6 而不是 2？
len 对字符串返回的是 UTF-8 字节数， 每个汉字占 3 字节。需要按字符处理时，用 str_contains / str_replace 等字符串函数， 不要依赖下标或 len。
为什么我的函数名报 already defined？
函数名全局唯一：所有函数扁平化存在于全局符号表， 不支持嵌套作用域遮蔽，重复定义直接报错。模块函数会带前缀 （如 math_clamp），命名时加前缀或分类可避免冲突。
