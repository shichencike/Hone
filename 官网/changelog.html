新增（标准输入函数）

v0.6.32026-08-16

新增（新语法）

  • continue 关键字：跳过本次循环剩余语句进入下一次迭代（与 break 相对，仅循环体内合法）
  • C 风格 for：for (init; cond; step) { ... } 三段式循环，各段可省略（for (;;) 无限循环配合 break）
  • do-while 循环：do { ... } while (cond); 先执行循环体再判断条件（至少执行一次）
  • 复合赋值：+= -= *= /= %=（str 仅支持 += 拼接）；自增/自减：i++ i--（后缀返回旧值）、++i --i（前缀返回新值）
  • 三元表达式：cond ? a : b（右结合可嵌套）；空值合并：a ?? b（a 为 null 取 b，短路求值）
  • 匿名函数 lambda：fn(x) { ... } 一等值（可赋值/传参/返回），创建时按值捕获环境（闭包），经变量名动态调用
  • 函数默认参数：fn f(a, b = 10) 调用可省略尾部实参；默认表达式调用时求值、可引用前面参数；必选参数位于默认参数之前；lambda 同样支持；hone build --dll 暂不支持（明确报错）
  • 三引号原始字符串："""...""" 多行字符串，不做转义处理、原样保留换行与缩进
  • 新增综合示例 examples/new_syntax_demo.hn（覆盖全部新语法，含 fmt 往返验证）

文档

  • hone.md（1.4 控制流、1.11–1.15 新语法章节）、CHANGELOG.md 同步更新
v0.6.22026-08-16

新增

  • process 进程检测标准库（hone_lib/process.hn，纯 Hone 编写）： 枚举进程、按名称/PID 查找、结束进程；Windows 用 tasklist / taskkill， Unix 用 ps / kill -9，跨平台一致。函数：proc_os / proc_list / proc_find / proc_exists / proc_by_pid / proc_count / proc_pids / proc_names / proc_kill / proc_kill_by_name；详见 标准库文档

  • 新增示例 examples/test_process_lib.hn、examples/test_sched_lib.hn

v0.6.12026-08-14

性能（解释器深度优化）

  • 函数定义 Arc 共享：消除每次调用的 AST 深拷贝（递归 fib(26) 约 3.4s → 1.6s）
  • 循环作用域复用 + 原地赋值更新：消除每轮迭代的堆分配与 String 分配 （2000 万次纯循环 71s → 42s；字符串拼接 20 万次 90s → 20s，预分配容量免 O(n²) 整串复制）
  • 解释器整体基准提升约 40%–78%，语义完全不变；移除 once_cell 依赖（改用标准库 LazyLock）、清理死字段，编译警告清零
  • 官网兼容 Android 8.1（Chrome 61 级 WebView）：flex gap 改为 margin 间距

新增

  • alias 别名增强：原名支持点号路径（alias time.now as tnow; 之后可 tnow(...) 调用），别名可叠加（别名再起别名）、可指向内置函数（alias print as p;）； 新增示例 examples/alias_demo.hn
  • music 乐理标准库（hone_lib/music.hn，纯 Hone 编写）： 音名 ↔ MIDI 编号 ↔ 频率换算、音阶与和弦生成（16 种音阶 / 20 种和弦）、时值与 BPM、 音程与移调、调号与调性、顺阶和声、音分与纯律比率；详见 标准库文档

文档

  • hone.md（4.4 别名、6.2 编译优化实测说明）、README（性能基准表 + alias 用法 + 版本号同步）、 官网 docs.html / examples.html / changelog.html / index.html 同步更新
v0.6.02026-08-09

新增

  • class 类：class 名称 { fn 方法(...) { ... } } 将相关函数组织成命名空间， 经 类.方法(...) 调用；成员函数不进全局符号表（裸名调用报 H002，同名全局函数可与类方法共存）； 类内互调用限定名；类名与 struct 名不重复；支持参数/返回值/递归/-> type 注解
  • 泛型：fn name[T, U](参数) -> T 声明类型参数，注解可引用（x: T）； 调用时按实参自动推导，同一泛型函数可不同类型多次调用、互不锁定； 编译期擦除——运行期零成本、不产生重复代码；类方法同样支持泛型
  • 标准库大规模扩展（内置函数，开箱即用）： csv.*（解析/序列化）、yaml.*、glob.* 与 temp.*、 zlib.* / gzip 压缩、stat.* 统计与 matrix.* 矩阵、 diff.* 文本对比与 regex.find/groups/split、 time.add/diff/weekday（WW 星期占位符）、 http.request（method/headers/body/timeout，可自定义 User-Agent）、 smtp.send（发邮件）、ws.request（WebSocket，支持 wss://）、 plot.bar/line（SVG 图表）、sqlite.*（运行时加载系统 libsqlite3，零 C 构建依赖）
  • 语言特性：点号后允许关键字作为模块成员名（如 glob.match、random.int、plugin.load）
  • 新增示例 examples/stdlib_test.hn、examples/class_test.hn、examples/generic_test.hn

文档

  • README、hone.md、官网 docs.html / stdlib.html：补充 class 类、泛型与全部新标准库模块

v0.4.02026-08-08

新增

  • typed FFI：load "lib" as m { fn f(p: ty, ...) -> ret; ... } 签名块显式声明 C ABI 参数与返回类型， 支持 int（int64_t）/ float（double）/ bool / str（const char*）/ ptr（void*）/ void（返回）， 调用时按声明精确转换，替代此前全 int64 单通道；参数最多 8 个，Windows / Linux / Termux ABI 一致
  • 静态检查：签名块声明的函数调用在检查阶段校验参数个数与类型（H001/H005），返回类型参与类型推导； 未声明签名的库函数保持旧 int64 通道调用（完全向后兼容）
  • 新类型 ptr：FFI 返回值/参数可传递不透明句柄，p == 0 判断 NULL；to_str(p) 输出 0x 十六进制
  • 头文件自动绑定：load "lib" as m from "header.h"; 从 C 头文件提取函数原型自动生成签名 （受限解析器：跳过注释/预处理/struct 定义/extern "C" 块，typedef 简单展开，属性宏跳过； 回调/变参/数组/结构体按值/long double 标记 unsupported，调用时直接报错而非 ABI 崩溃）
  • 新命令 hone bind <header.h>：离线生成 typed load 签名块（可直接粘贴进脚本）
  • 新增示例 examples/ffi_demo.hn（typed FFI 全类型演示）、examples/ffi_header.hn（from 头文件自动绑定演示）

变更

  • 语言更名：Zap → Hone（二进制 hone、扩展名 .hn、错误码 Hxxx、缓存目录 ~/.hone）
  • 新增 GitHub Actions CI（Windows/Linux 构建测试 + Termux aarch64 交叉编译）与 tag 触发自动发布 （三平台二进制 + 校验和 + 一键安装脚本 → GitHub Releases 附件）
  • 新增一键安装脚本 install.sh / install.ps1（sha256 校验）
  • 官网部署至 hone.xo.je
