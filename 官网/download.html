#下载中心

Hone 是单文件可执行程序：下载 → 解压 → 运行，零依赖、零配置。当前最新版本 v0.5.0，所有二进制均从 GitHub Releases 分发。

直接下载（GitHub Releases）

🪟 Windows x86_64
hone-windows-x86_64.exe
64 位 Windows 10 / 11，无需安装，双击或命令行直接运行
下载
🐧 Linux x86_64
hone-linux-x86_64
musl 静态编译，不依赖系统 glibc，任何发行版直接运行
下载
🤖 Termux（Android）
hone-termux-aarch64
Termux 终端环境（ARM64），静态编译开箱即用
下载
校验和：每次发布附带 checksums.txt， 用 sha256sum（Windows 用 Get-FileHash -Algorithm SHA256）比对下载文件的哈希。 全部历史版本见 GitHub Releases。

一键脚本安装（推荐）

脚本会自动下载对应平台二进制、校验 sha256 并安装，无需手动管理文件：

// Linux / Termux
curl -fsSL https://github.com/shichencike/Hone/releases/latest/download/install.sh | sh

// Windows（PowerShell 5.1+）
irm https://github.com/shichencike/Hone/releases/latest/download/install.ps1 | iex

指定版本：HONE_VERSION=v0.5.0 curl -fsSL .../install.sh | sh（Windows 先 $env:HONE_VERSION = "v0.5.0"）。详细说明见 安装教程。

源码构建

需要 Rust 工具链（rustc ≥ 1.71）：

git clone https://github.com/shichencike/Hone.git
cd Hone
cargo build --release
// 产物: target/release/hone（Windows 为 target/release/hone.exe）
./target/release/hone --version
