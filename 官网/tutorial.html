#默认值教程：给任何输入设兜底值

三步教会你在 Hone 里给输入设默认值：函数参数默认值、标准输入默认值（EOF 降级）、命令行参数默认值。 完成后你的脚本在缺少输入时不再崩溃，而是优雅地使用兜底值继续运行。

  1. 函数默认参数（省略尾部实参）
  2. 标准输入默认值（EOF 降级）
  3. 命令行参数默认值
  4. 为什么 ?? 兜不住输入？
  5. 完整示例

第 1 步：函数默认参数

定义函数时给参数写上 = 默认值，调用时就能省略尾部实参：

fn greet(name, greeting = "Hello") {
    return greeting + ", " + name + "!";
}
print(greet("Hone"));           // Hello, Hone!
print(greet("Hone", "Hi"));     // Hi, Hone!

要点：

  • 默认表达式在调用时求值，可引用其前面的参数（如 fn f(a, b = a * 2)）
  • 必选参数（无默认值）必须位于默认参数之前，否则编译报错
  • 参数个数按「必选个数 ~ 总个数」区间检查；lambda 参数同样支持默认值
  • 限制：hone build --dll 暂不支持默认参数（报错提示改用解释模式）

第 2 步：标准输入默认值（EOF 降级）

input / read_int / read_float 从标准输入读取一行。当输入源关闭（管道结束 / Ctrl+Z / Ctrl+D）时抛 error[H306]， read_int / read_float 遇到格式非法分别抛 error[H006] / error[H007]。 给输入设默认值的标准做法是用 try-catch 包装：

fn ask(prompt, fallback) {
    try {
        return input(prompt);
    } catch e {
        return fallback;   // H306 EOF → 返回默认值
    }
}
name = ask("姓名: ", "匿名");
print("你好, " + name + "!");

数字输入同理——一个 catch 同时兜住格式错误 H006/H007 与 EOF H306：

fn ask_int(prompt, fallback) {
    try {
        return read_int(prompt);
    } catch e {
        return fallback;   // H006 格式错 / H306 EOF → 返回默认值
    }
}
age = ask_int("年龄: ", 0);
print("明年你 " + to_str(age + 1) + " 岁");

想体验 EOF 降级：直接运行脚本然后按 Ctrl+Z（Windows）/ Ctrl+D（Unix）， 或让管道不喂数据：hone script.hn < /dev/null —— 输出将使用默认值而非报错。

第 3 步：命令行参数默认值

args.get 原生支持类型转换与默认值： 第三个参数就是 key 缺失时的兜底值（缺省为 null）：

port = args.get("port", int, 8080);   // --port 9090 → 9090；缺省 → 8080
ratio = args.get("ratio", float, 1.5); // --ratio 2.5 → 2.5；缺省 → 1.5
print(port, ratio);

type 支持 int / float / bool / str，可直接写类型关键字（表达式位置等价于其名称字符串）。

为什么 ?? 兜不住输入？

a ?? b 空值合并只对 null 值生效——比如 void 函数调用的占位值。 而 input 在 EOF 时抛错误而不是返回 null， 所以 input(...) ?? "匿名" 不会生效，必须用 try-catch 捕获后降级。

补充：与 ?? 同属 null 语义的还有可选链 a?.b（a 为 null 时短路返回 null，可链式并与 ?? 组合）， 详见手册 §7.7 多返回值 · 解构赋值 · 推导式 · 可选链。

完整示例

把三步结合起来：函数默认参数 + 输入 EOF 降级 + 命令行参数默认值，写一个可交互、可批处理的小脚本。

// demo.hn — 交互式输入，管道/EOF 时自动降级
fn ask(prompt, fallback) {
    try { return input(prompt); }
    catch e { return fallback; }
}
fn ask_int(prompt, fallback) {
    try { return read_int(prompt); }
    catch e { return fallback; }
}

name = ask("姓名: ", "匿名");
age  = ask_int("年龄: ", 0);
port = args.get("port", int, 8080);
print(f"{name} 明年 {age+1} 岁，端口 {port}");

交互运行：hone demo.hn 后键入 Bob 与 25； 批处理运行：printf 'Bob\n25\n' | hone demo.hn； EOF 降级：hone demo.hn < /dev/null → 匿名 明年 1 岁，端口 8080。

可运行的完整源码见 examples/input_default_demo.hn， 手册参考见 §8 内置函数参考。
